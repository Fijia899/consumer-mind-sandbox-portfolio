# 旅游意向人群心智沙盘｜项目作品集

本仓库是项目成果展示包，呈现 JTBD 研究思路、原型实现材料和交付校验方式。当前消费者沙盘的研究对象为旅游意向人群；本作品集用于介绍项目结构和工程实践，不等同于完整部署包，也不单独证明研究结论已经通过真实用户验证。

## 项目概览

项目希望把旅游意向人群的任务、决策因素和期望结果整理成可讨论、可迭代的研究模型，并通过原型探索从研究输入到分析输出的工作流程。JTBD 用于描述用户要完成的任务及其进展条件；原型输出用于辅助研究和方案比较，仍需结合来源资料与后续反馈进行判断。

## 仓库内容

| 路径 | 内容 |
| --- | --- |
| `01_BP/` | 项目方案文档，说明问题、产品设想和实施路径 |
| `02_implementation_delta/` | 原型代码、研究数据结构、界面、服务逻辑、文档与自动化测试 |
| `03_validation/` | 作品集文件完整性与交付结构校验 |

该目录主要用于阅读和审阅项目成果。运行原型前，请先检查 `02_implementation_delta/` 内的依赖说明、环境配置和启动脚本；不要将其视为生产部署配置。

## 研究与产品工作

- 梳理旅游意向人群的 JTBD 任务、步骤、期望结果与推动/阻碍因素。
- 将研究维度组织为可维护的数据结构，供原型界面和分析流程使用。
- 设计研究资料、分析输入和结果反馈之间的工作流，并为关键环节编写验证。
- 对涉及风险的输入设置识别与拦截逻辑；原型提示不能代替专业判断或真实服务流程。
- 通过方案文档、代码和验证材料展示从问题梳理到原型交付的过程。

## 作品集说明

这里收录的是阶段性展示材料。目录中的原型与方案文档应结合各自内容阅读；它们不自动代表当前旅游研究模型已完成适配，也不能据此推断旅游意向人群的总体偏好。新增或修订研究结论时，应回到可追溯的旅游研究资料，并清楚区分原始陈述、研究者解释和模型推断。

适合简历的项目描述：

> 围绕旅游意向人群研究，参与构建基于 JTBD 的心智沙盘原型；将任务、决策因素和期望结果组织为可维护的数据模型，设计研究输入、方案分析与反馈校验流程，并通过自动化测试验证关键功能与交付完整性。
