# 旅游意向人群心智沙盘｜项目资料

基于 JTBD 方法整理旅游意向人群研究框架与项目方案：

> Job / Step / Outcome / Force + 研究维度 + 项目计划

## 项目内容

- **研究框架**：围绕旅游任务、任务步骤、期望结果与推动/阻碍因素组织研究问题。
- **项目方案**：说明研究目标、产品设想与实施路径。
- **文件校验**：检查方案文件完整性与资料包结构。
