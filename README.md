# 旅游意向人群心智沙盘｜项目资料

本仓库整理旅游意向人群研究框架与项目方案，使用 JTBD 方法将研究问题组织为：

> Job / Step / Outcome / Force + 研究维度 + 项目计划

本仓库是项目资料包，包含项目方案和资料完整性校验，不是可直接启动的 Web 应用。方案围绕有旅游意向、正在选择或规划出行的人群展开；文档中的画像和场景用于研究设计，不应视为真实访谈结论或市场统计。

## 项目内容

- **研究框架**：围绕旅游任务、任务步骤、期望结果及推动与阻碍因素组织研究问题。
- **项目方案**：说明研究目标、产品设想、研究维度和实施路径。
- **资料校验**：检查方案文件是否完整，并确认资料包结构符合预期。

## 仓库目录

```text
.
├── 01_BP/
│   └── 消费者心智沙盘_BP.pptx  # 项目方案
├── 03_validation/
│   └── test_package.py          # 资料包完整性校验
└── README.md                    # 项目说明
```

## 使用方式

1. 阅读 `01_BP/消费者心智沙盘_BP.pptx`，了解研究框架、目标和项目计划。
2. 变更或重新整理资料包后，在仓库根目录运行校验，确认方案文件和目录结构完整。

## 研究边界

- 研究对象为旅游意向人群，研究问题、场景和示例均围绕旅行决策与出行任务。
- JTBD 任务结构用于组织需求与方案分析，不代表已经验证的用户结论。
- 合成画像、假设场景和项目设想需要后续通过真实研究验证。
- 资料包校验仅检查文件及结构，不评价研究结论的真实性或有效性。

## 验证

在仓库根目录运行：

```powershell
python -m pytest -q 03_validation
```

测试会校验项目方案文件、文件摘要以及仓库资料结构。
