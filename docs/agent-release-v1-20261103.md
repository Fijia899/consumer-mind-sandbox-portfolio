# 消费者沙盘 Agent 第一版实现与验证

> 历史研究或实施记录：本页保留当时范围与验证结果。当前操作、页面和测试命令请以[项目 README](../README.md)及[文档索引](README.md)为准。

## 可用入口

- `/`、`/agent`：个性化与通用分析工作台。
- `/participants`：原真人档案、冻结预测与本人反馈。
- `/sources`、`/jobs`、`/research`：原有来源、任务地图与只读归档。

## 本次已实现

个性化链路支持聊天文本、TXT/JSON 导入、录音上传及本地转写、说话人与转录文字核对、AI 画像草稿、画像审核、角色选择和逐项方案需求分析。画像的事实与推断必须引用所选对象的发言；角色库也可直接创建明确标记的假设原型。原有真实来源研究按独立旅行情境读取，不修改原研究台账。

通用链路内置 24 个公开定义的规则原型，涵盖 8 类旅行同行/体验情境与 3 类决策偏好。可勾选范围并加入自定义原型，每次最多 48 个不同原型。Agent 按模型选择的工具分析批次、识别缺口、形成候选方案；每个需求结果校验 ID 完整性与方案逐字引用。覆盖分母固定，未知与失败不移除，不作为真实人口比例。

报告支持对话讨论取舍、生成待验证方案、在同一冻结画像集合上重新分析、查看前后差异、引用侧栏与 Markdown 导出。讨论新方案不会直接改写旧分析的状态或声称覆盖已提升。

运行记录支持轮询查看、刷新恢复查看、幂等提交、取消、时间与模型调用上限、实际用量和失败记录。服务重启将未完成任务标记为中断。录音可从资料库删除，关联的转录、画像、运行快照及报告一并删除。

## 模型与音频配置

分析沿用项目 `.env` 中的 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`，密钥不发送到前端。没有有效模型时任务明确失败，不用规则或伪造结果冒充模型输出。更新配置后重新启动服务，以重新加载环境变量。

录音采用 [faster-whisper](https://github.com/SYSTRAN/faster-whisper) 在本机 CPU 转写，首次使用下载多语种模型；可配置 `TRAVEL_ASR_MODEL`，默认 `small`。模型只做转写，不确认现实身份或自动认定说话人。安装可选依赖：

```powershell
python -m pip install -r backend/requirements-audio.txt
```

限制为 MP3/M4A/WAV、25 MB、20 分钟、最多 240 段/40,000 字。上传前需确认资料可用于分析。音频在本机处理；提取画像与方案分析仍需把必要文字传给配置的模型服务。

## 数据与恢复

新增运行和角色保存在 `data/agent.sqlite3`；录音、转录模型缓存位于 `data/agent_media/`。两者已被 Git 忽略。继续采用本机单用户、单服务进程模式，尚未提供公开多用户账户隔离。

备份时停止服务，再复制数据库与媒体目录；恢复时同时恢复这两部分，避免只恢复报告却丢失音频。升级前代码标签 `pre-agent-upgrade-20261103` 和 [原文件备份说明](agent-upgrade-plan-v1-20261103.md) 保留。Git 回滚不自动回滚新增私有研究数据。

## 验证记录与限制

- Python 全量测试 186 项通过；四套无界面浏览器回归与全部前端 JavaScript 语法检查通过。
- 新增隔离测试覆盖来源归属、草稿审核、乐观版本锁、原型隔离、批次完整性、冻结集合对照、未知/失败分母、讨论不篡改结果、幂等、取消、预算、重启和媒体级联删除。
- 新增浏览器回归使用临时数据库及明确的模型/转录夹具，覆盖添加角色到报告对照、24 原型批量、文本转义、手动原型、录音说话人核对、删除、导出、历史与移动端。夹具结果不进入正式台账，也不表示模型实测质量。
- 本机真实音频处理已使用约 10.6 秒的中文合成测试录音验证，成功输出 3 个带时间戳的片段，转写约 7.2 秒。此结果只验证本机链路，不能代表真实电话噪声、多说话人或长录音的准确度。
- 当前配置的模型接口真实联调返回 HTTP 401（令牌无效）。程序已提供明确错误和配置指引；需更新有效密钥后，才能完成真实画像提取、Agent 分析和讨论的质量验收。暂不报告真实模型成功率、意向准确率或业务提升。

V2 中的自动扩充原型、代表性样本权重、公开部署及真人预测效果验证仍需后续工作。候选修改的业务成本与服务可兑现性需要研究者核实；用户填写的约束传给模型保留分析，尚无独立的成本/资源业务系统验证。当前版本不会自动对接销售、联系受访者或预订旅行。
