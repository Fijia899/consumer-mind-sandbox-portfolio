# 当前版本核对记录（2026-11-13）

## 当前产品

研究对象为旅游意向人群。工作台支持生成 1–60 位合成画像，输入旅游方案和业务约束，由研究 Agent 分析原方案、生成修改稿并用同一组画像复测。实际工具事件、逐人依据、修改明细和 Markdown 报告在工作台提供。尚无生成画像时，Agent 使用 6 个内置旅游假设画像。

“快速规则仿真”保留无密钥测试入口，决策维度在 `/admin` 管理。Agent、模型画像和个性化表达需要有效模型配置。模型画像每位最多尝试 3 次，整批通过后保存；失败保留上次成功结果。

此次同步本地已实现的 Agent、差异化画像生成、前端及配套测试，保留发布版的隔离测试、部署配置和运行数据排除规则。当前使用方式见 [README](../README.md)、[使用手册](../使用手册.md) 和 [规格](../SPEC.md)；历史方案仅作为过程记录。
